🌍 WorldNet Android App

The Android application of WorldNet – Global Internet Sharing Platform.

Features

- User Login & Signup
- Share Internet
- Connect Internet
- Generate 8-Digit Connection Code
- Secure User Permission
- Support for 5–10 Users
- Connection Status
- Data Usage Monitoring
- Disconnect Anytime

Technology

- Kotlin
- Android Studio
- Android SDK
